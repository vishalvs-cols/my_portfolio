# 🌐  Portfolio 

A modern, clean, and responsive **portfolio** built using **HTML5 and CSS3**. The portfolio is designed to showcase my skills, projects, learning journey, and contact information in a simple and professional interface.

The website includes dedicated **Home, About, Projects, Contact, and Social Media** sections with a responsive layout for desktop, tablet, and mobile devices.

---

## 📌 About the Project

This project is a personal portfolio website created to present my profile as a web developer and showcase the projects and technical skills I am currently developing.

The portfolio focuses on:

- Clean and modern UI
- Responsive web design
- Simple navigation
- Project showcase
- Skills presentation
- Contact form
- Social media integration
- Mobile-friendly layout

## 🎨 Design & UI

The website uses a clean and modern visual style with:

- Dark navigation bar
- Gradient hero section
- Orange accent color
- Card-based project layout
- Rounded buttons and components
- Responsive typography
- Hover animations
- Mobile-friendly layouts

The stylesheet includes responsive media queries that adjust the navigation, hero buttons, About section, project cards, and contact form for smaller screens.

---

## 📱 Responsive Design

The website is designed to work across:

- 💻 Desktop
- 💻 Laptop
- 📱 Tablet
- 📱 Mobile

On smaller screens, the project cards change from a horizontal layout to a vertical layout, while the About section changes to a single-column design.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash

```

### 2. Open the Project

Navigate to the project folder:

```bash
cd your-repository-name
```

### 3. Run the Website

Open:

```text
index.html
```

in your preferred web browser.

Alternatively, you can use **Visual Studio Code with Live Server** to run the project.
